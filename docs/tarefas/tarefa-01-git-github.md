## Status

✅ **Concluída**

## Objetivo

Configurar o Git, utilizar uma conta GitHub vinculada ao ambiente acadêmico, criar o repositório do projeto e realizar commits e pushes com sucesso.

## Implementação no EduTrack Orbit AI

O projeto está versionado com Git e hospedado no GitHub acadêmico.

**Repositório acadêmico:**

`marcospalvesTEC/EduTrack-Orbit-AI-up`

O histórico completo do projeto foi preservado durante a migração para a conta acadêmica, incluindo commits e branches já existentes.

O repositório local está configurado com dois remotes:

- `origin`: repositório acadêmico;
- `pessoal`: repositório pessoal usado anteriormente no desenvolvimento.

Isso permite que o desenvolvimento acadêmico continue na conta da faculdade sem perder o histórico original.
